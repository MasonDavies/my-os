# my-os
FortOS

My Fortnite-themed web operating system.

FortOS is a Fortnite-inspired webOS featuring tools designed to help your gameplay. Plan your rotations, take notes, and mark up the season map

Features:

📝 Rotation Notes

Write down rotation plans, strategies, and important locations to help prepare for your next match.

🗺️ Paint Map

Draw directly on the current season's Fortnite map to mark rotations, locations, routes, and strategies.

🔍 Search Engine

Search for useful Fortnite information using this integrated search tool

📈Stat Tracker📊

Check your stats LIVE using the integrated fortnite tracker

Try it yourself:

1. Open masondavies.github.io/my-os in your browser.
2. Launch Rotation Notes to record your strategies.
3. Open Paint Map to draw on the season map and visualize your plans.
4. Use the tracker to analyze your growth
